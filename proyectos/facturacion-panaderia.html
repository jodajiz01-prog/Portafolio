Facturación para una panadería familiar

Una herramienta para registrar ventas y mantener los comprobantes organizados, diseñada a partir del trabajo diario de una panadería.

  • Python
  • Flask
  • SQLite
  • HTML
  • CSS
  • JavaScript

El problema

La panadería necesitaba una forma más ordenada de registrar sus ventas que las facturas de papel. El objetivo fue crear una aplicación sencilla de usar desde un celular, con botones claros y pocos pasos para completar una venta.

La solución

Desarrollé una aplicación web con acceso por usuario, gestión de productos y un flujo para preparar, revisar y guardar comprobantes internos. El diseño se fue ajustando con las pruebas de la persona que la utiliza en el negocio.

Ventas y comprobantes

Búsqueda de productos, cantidades, cálculo de IVA configurado y revisión antes de guardar. Los comprobantes se pueden consultar e imprimir.

Precios flexibles

El catálogo conserva los precios habituales y permite aplicar un precio general a una factura para acuerdos con clientes.

Organización

Historial con búsqueda por cliente y fecha, anulación con motivo y descarga de copias de seguridad.

Uso cotidiano

Interfaz adaptable para celular, con textos y controles grandes. Se prepara la recuperación de una factura pendiente en el mismo navegador.

Estado y siguientes pasos

El proyecto está en etapa alfa y se utiliza para probar el registro interno de ventas. Entre los siguientes pasos están mejorar la recuperación de datos y preparar la integración con la facturación electrónica de Hacienda.

Actualmente los comprobantes son registros internos: la aplicación todavía no los envía a Hacienda. Por privacidad, no se muestran datos de clientes ni acceso a la aplicación.
